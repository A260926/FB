The packets are built by make_fixture.cjs, which writes Vorbis LSB-first setup fields: two scalar books, one floor1, one uncoupled two-channel submap, residue type 2 and a short 64-sample mode. Each active floor has y0=y1=255; the other floor is absent. The two audio packets are identical. left/right.f32 are the 32 interleaved output frames produced by FFmpeg 8.0.1's native Vorbis decoder from left/right.ogg using `ffmpeg -v error -y -i harness/left.ogg -f f32le harness/left.f32` and the corresponding right command. Generation logs and compiler versions are outside the seed; no FFmpeg executable is required to run the tests. Format source: https://xiph.org/vorbis/doc/Vorbis_I_spec.html , residue type 2 and floor1 sections. The fixture and generator are original for this draft; distributed under MIT with the repository.

Rebuild the public packets with `node harness/make_fixture.cjs`; no Python is used. The Node generator reproduces the frozen JSON and Ogg files byte-for-byte.
