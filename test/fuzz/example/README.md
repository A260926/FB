# Runnable example

* `mega-plan.wren` - the benign Wren program rendered from the combined fixed
  plan (`./upfuzz --render 0`). It exercises, in one source file: shared-cell
  read/write closures, a Fiber suspended with an open capture, two-level
  indirect capture, a closed capture after scope exit, same-name shadowing,
  same-slot reuse, a deep stack-growing call and host-retained handles.
* `mega-plan.upv` - the encoded wire bytes for the same plan. It is the exact
  input the fuzz entry point decodes.

Replay it through the public API chain with:

```sh
./upfuzz test/fuzz/example/mega-plan.upv
```

The `.wren` file is what `upRenderProgram()` produces from that byte stream;
it is not hand-written and is regenerated by the driver.
