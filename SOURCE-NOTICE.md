The original upstream Readme.md declares that this project is distributed under the DO WHAT THE FUCK YOU WANT TO PUBLIC LICENSE. That declaration is retained verbatim. Upstream has no separate LICENSE file and does not specify a version in that declaration. The supplementary LICENSE file is the unmodified text published at https://www.wtfpl.net/txt/copying/ and is supplied for offline reading; its version label does not add an upstream version claim. The original `vec3`, `Material`, `Sphere` and the sphere/ray intersection were extracted into the shared inline header `core.h` (with an added double-precision vector for fiber math); `tinyraytracer.cpp`, including `cast_ray` and its default image, keeps the same behavior and baseline output. `task_support` holds the fixed-source baseline and test driver; the fiber preview path (`fiber.*`, `fiber_renderer.*`, `tests/`, `examples/`) is new code.
