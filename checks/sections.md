# Plane-section regression (s1851 + s1314)

This check exercises the two-step SISL plane-section path used by the
section preview: `s1851` finds the branches in the surface parameter
domain, then `s1314` marches each branch into a geometric curve
(`pgeom`) and a parameter-plane curve (`ppar1`).  All inputs are
generated by `checks/intersections.c` from independent analytic models;
nothing is read from a windowing library, a third-party test framework
or the network.

The production intersection code in `src/` is not modified.

## Models

Every model is stored as an analytic description plus its valid spline
parameter range and its expected connected components.  Assertions key
off that description, never off the order or orientation in which SISL
returns curves.

A physical-space similarity `x = scale*b + trans` maps each base model
into the checked configuration, and the plane equation is transformed
analytically with it.

### 1. Two-branch graph (baseline family)

Base surface `b(u,v) = (u, v, (u-0.25)(u-0.75))` on `[0,1]^2`, section
plane `z = h`.

* `h = 0` gives two straight lines `u = 0.25` and `u = 0.75`, each
  running from the boundary `v = 0` to `v = 1`.  This is the existing
  `checks/baseline.c` geometry.
* The offset variant uses `h = 0.02`; the roots move to
  `0.5 +/- sqrt(0.0625 + h)` and are stored analytically.

The spline is a degree-(2,1) polynomial B-spline whose coefficients are
the quadratic/linear blossom values of the exact coordinate
polynomials, so the spline reproduces the analytic graph to round-off.

### 2. Paraboloid with an interior circular zero set

Base surface `b(u,v) = (u, v, (u-0.5)^2 + (v-0.5)^2 - 0.16)`, plane
`z = h`.  For `h = 0` the zero set is the circle of radius 0.4 centered
at `(0.5, 0.5)`, strictly inside the parameter box (the patch corners
sit at height 0.34, so the circle never touches a boundary).  The offset
variant uses `h = -0.07`, radius `sqrt(0.16 + h)`.

A single Bezier patch cannot expose a closed loop that has no boundary
contact: the recursive subdivision only sees a sign change after a
split.  The surface is therefore built as a degree-2 spline with two
interior knots per direction (five control points), again with exact
blossom coefficients.  SISL reports one closed loop (`itype = 2`).

### 3. Rational cylinder band cut by an oblique plane

A NURBS cylinder band of radius 1, made from three 90-degree quadratic
circular arcs (270 degrees total, an open non-degenerate arc that never
meets a periodic seam), times a linear axis segment.  All weights are
strictly positive (the odd control-point weight is
`cos(45 deg) ~ 0.7071`).  The homogeneous xy coordinates hold
`R*(cos theta, sin theta)`, which puts the odd middle control points at
the tangent intersection `R/w`; the translation enters multiplied by
the weight.  With that construction `s1424` returns radius 1 to
round-off everywhere.

The section plane is oblique, `z = 0.3 x + 0.4`
(normal `(-0.3, 0, 1)`).  Its section is a non-degenerate curved helix
segment spanning the full analytic angle range
`[-3 pi/4, 3 pi/4]`, not a straight line.  The offset variant raises
the plane to `z = 0.3 x + 0.7`; both planes stay well inside the
`[0, 2]` axis range over the whole arc.

### 4. No-hit control

The paraboloid intersected with plane `z = 0.4`, above its patch
maximum of 0.34.  The required result is zero curves and zero isolated
points; finding any branch is a failure.

### Transform coverage

Each of the three intersecting families is checked in four
configurations:

1. base position;
2. nonzero plane offset (described above);
3. uniform scale 2.5 plus translation `(0.7, -0.4, 1.1)`;
4. a non-unit affine reparameterization onto the spline domain
   `r in [1.3, 4.7], s in [-2.1, 0.9]` (base parameters recovered by
   `u = (r - 1.3)/3.4`, `v = (s + 2.1)/3.0`).

## What each callback group asserts

Each named callback returns 0 only after completing its assertions;
any nonzero result (including 77, the skip code) fails the driver.

### topology

The number of connected components must equal the analytic expectation:
2 for the two-line family, 1 for the circle and cylinder, 0 for the
no-hit control.  Isolated intersection points must be zero for every
benign model.

### paired-curves

Each returned branch is sampled at 201 points across its own parameter
span.  At every sample the driver evaluates `pgeom`, evaluates
`ppar1`, and feeds the two parameter coordinates back through the
surface with `s1424`.  It then checks:

* the two spatial positions agree (the independently fitted geometric
  and parameter curves still describe the same points);
* both positions satisfy the independent, normalized plane equation;
* both positions satisfy the independent surface equation
  (`(u-0.25)(u-0.75) - z = 0`, the paraboloid equation, or
  `b_x^2 + b_y^2 - R^2 = 0` in de-transformed coordinates);
* for the polynomial graphs, the spline position additionally equals
  the analytic model evaluated at the same parameters.  The rational
  cylinder has an exact but nonlinear parameter-to-angle map, so its
  independent model check is the cylinder equation rather than an
  equal-parameter position comparison.

The space-curve parameter is never used as a surface parameter; only
`ppar1` coordinates are fed back to the surface.

### analytic-coverage

"Every returned point lies on the plane" does not prove the section was
traced completely, so coverage is checked against the analytic model:

* two-lines: the two branches are matched to the two analytic roots by
  their mid-parameter position, and each branch's endpoints reach the
  two opposite parameter boundaries;
* circle: exactly one component whose geometric and parameter-curve
  endpoints close, and whose sampled polar angles cover the full turn
  with no gap larger than one sixth of a circle;
* cylinder: the sampled section angles are sequentially unwrapped and
  must span the whole analytic arc, including both arc endpoints;
  returning only a segment violates the endpoint/gap budgets.

## Step length and tolerance budget

Three error sources are kept separate:

1. **Input length scale `L`** (1 for the base models, 2.5 after the
   similarity transform).  Every geometric threshold scales with `L`,
   so a transformed model is never checked against an absolute budget
   sized for the unit model.
2. **SISL geometry resolution** `epsge = 1e-8 * L`, with computational
   resolution `epsco = 1e-12`.  These are the values handed to `s1851`
   and `s1314`.
3. **Sampling discretization**: 201 uniform samples per curve span.
   The coverage gap budgets (one sixth of the analytic angle range,
   endpoint error below one fiftieth of the arc) are deliberately
   coarser than the per-sample geometric budgets so that sampling
   density, not curve precision, limits the coverage check.

The maximal marching step follows the length scale:
`amax = 0.01 * L`.  On the untransformed cylinder oblique section the
step was halved repeatedly before fixing the budget; the maximum
`pgeom`-vs-surface pairing error converged as

| amax  | max pairing error |
|-------|-------------------|
| 0.200 | 5.3e-4 |
| 0.100 | 1.0e-3 |
| 0.050 | 1.2e-3 |
| 0.025 | 2.1e-4 |
| 0.010 | 6.6e-6 |

so `amax = 0.01 L` is used everywhere.  Because `pgeom` and `ppar1`
are fitted independently, their pairing budget is **not** the
intersection tolerance: it is `2e-5 L` for pairing and the
geometric-curve surface residual, `1e-7 L` for the plane equations,
and `1e-6 L` for back-substituted surface residuals.  Observed values
on the normal sources stay at or below 1.7e-5 for pairing and
1.2e-7 for plane residuals, with surface residuals at round-off for
the exact models.

All `s1851`/`s1314` statuses, curve pointers and allocations are
checked, and every SISL object is released through the matching
`free*` routine.  A nonzero warning status is treated as a failure.

## Mutation evidence (`checks/check-intersections.sh`)

Two independent temporary source copies prove the assertions have
bite.  Each copy is compiled from the full `src/` tree, runs the same
driver, prints finite `OBS` values, and is then rejected; compile
failures, crashes, timeouts and "no curves found" do not count.

* **missing-branch** — a guarded block in the copy of `src/s1851.c`
  frees and removes one branch whenever the topology result holds at
  least two curves.  `s1314` is untouched, so every surviving curve is
  geometrically valid and only a coverage check can detect the loss.
  It is rejected by `analytic-coverage` on `twolines-base` (one of the
  two boundary-to-boundary lines is missing).
* **marching-plane** — a guarded block in the copy of `src/s1314.c`
  adds `1e-4` to the normalized plane constant term; the `s1851`
  guide points are unchanged.  It is triggered on the non-degenerate
  oblique cylinder section (`cylinder-base`), where the observed
  geometric plane residual is exactly `1.00e-4` against the
  `1e-7 L` budget — far above the geometry error, while the offset is
  too small to push the section off the band boundaries.  It is
  rejected by the `paired-curves` geometric assertion, not by a
  straight-line fallback path.

The normal tree prints the three `PASS ... cases=N` lines and the
script finishes with `SISL_SECTION_QA_OK`; the two copies print
`DETECTED missing-branch` and `DETECTED marching-plane`.  No mutation
is present in the working `src/` tree.

## Excluded degeneracies

The suite is intentionally restricted to benign topology and does not
cover: tangent contact between plane and surface, singular or isolated
intersection points, zero-set components touching a parameter
boundary, periodic seams (the cylinder arc is open and shorter than a
full turn), self-intersecting sections, and surfaces whose weights are
non-positive or whose control net is singular.  These need their own
oracles and are out of scope for this offline regression.
