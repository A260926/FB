compressed.pcm is original signed little-endian 16-bit stereo PCM, 512 frames: left=int(12000*sin(i*.13)), right=int(8000*cos(i*.07)). FFmpeg 8.0.1 encoded it with `ffmpeg -v error -y -f s16le -ar 44100 -ac 2 -i checks/compressed.pcm -c:a alac checks/compressed.m4a`; its single packet was exported by `ffmpeg -v error -y -i checks/compressed.m4a -map 0:a:0 -c copy -f data checks/compressed.alac`. Both are retained so the single packet provenance is reviewable. The baseline streams two copies followed by an escaped stereo packet; the extra packet provides lookahead for the existing Rice reader. A compressed packet ending at physical EOF currently raises Aurora UnderflowError; this independent pre-existing EOF issue is not the target. No FFmpeg executable is needed during baseline or target runs. Original helper fixtures are Apache-2.0; upstream source headers retain their original license notices.
