These five DER files are public synthetic certificates created for the starting
behaviour witness. No private key is included or required at runtime. The fixture
bytes and the checks/ code added by this task are available under CC0-1.0.

root.der is a self-signed P-256/SHA-256 trust anchor; ca.der is an intermediate
with non-critical NameConstraints permitting the DNS subtree example.test;
ca-critical.der uses the same CA public key with that extension marked critical.
good.der has SAN service.example.test; outside.der has SAN outside.invalid.
All are valid 2020-01-01 through 2040-01-01. They do not identify real services.

Generated by an only C program using Mbed TLS 2.28.10 at commit
2fc8413bfcb51354c8e679141b17b3f1a5942561. Deterministic synthetic signing keys
were constructed in memory only and never written. Neither Mbed TLS nor a PKI
tool is needed to build/run this seed. The witness exercises the unmodified
minimal validator; it does not provide the new name-constraint implementation.
