# 原网格切线流

在 par_shapes_mesh 末尾加入拥有型可选 float* tangents，分配/释放沿用 PAR_* 宏，缺失为 NULL；所有库内创建的 mesh 均初始化它。新增 bool par_shapes_compute_tangents(par_shapes_mesh*)，只在成功时替换 mesh 的数组/计数及旧切线。输入为空、缺 P/N/UV、越界索引、非有限属性、零法线、计数溢出或分配失败返回 false，保留原 mesh 的指针和内容。法线允许非单位，计算以其单位方向为准，不改已有法线数值。成功后每点 T 有限、单位并与 N 正交，w 仅为±1。

每面令 e1=P1-P0、e2=P2-P0，du/dv 同理；D=du1*dv2-du2*dv1。位置叉积长度为 A。A<=1e-12 或 |D|<=1e-12 的面不贡献。其余面 T=(e1*dv2-e2*dv1)/D，B=(e2*du1-e1*du2)/D，每角贡献为 A*T、A*B；每角类别是 sign(dot(cross(normalize(Ncorner),T),B))，绝对值<=1e-12时该角无贡献。每个原顶点的正负类别独立累积；先按原面/角顺序遇到的有效类别留在原索引，另一类别在所有原顶点之后按首次遇到顺序追加副本。无贡献角指向原索引。不同原顶点永不合并，同类共享点不展开。追加点复制原P/N/UV。原顶点顺序保留，面/角顺序不变。每点把累计T投影到法线垂面并单位化，w由累计B判定；累计T不可单位化或该点无贡献时，用与N绝对点积最小的正坐标轴投影单位化作T（并列按X/Y/Z），w=+1。重复计算不继续增加顶点。这里只定义上述切线，不要求MikkTSpace兼容。

par_shapes_create_parametric 在原 welded normals 完成后调用此入口。因此沿此路径返回的P/N/UV有效网格有切线，平面、环面、球体都包括；零面积的球极点面走上述无贡献规则。其余没有UV或法线的生成器保持无切线。保留原生成器的P/N/UV、面绕序和UV周期副本，不按位置给不同UV的点共享切线。生成后还会改几何/重算法线的专用生成器必须在最终几何上建立切线或明确保持NULL，不能发布中途旧帧；平面、圆柱、圆锥、球、半球、环面需最终有切线。生成器新增切线分配失败可清理后返回NULL，不要求改造旧的所有分配失败路径。

原操作的约定如下，必须改原入口而非只在新API里补偿：
- free_mesh释放切线；clone深拷贝所有存在流，复用目标时清除源缺失的N/UV/tangent；clone(m,m)无操作。成功副本彼此独立。
- merge及merge_and_free：非空两端N、UV各取交集（任一缺则释放结果对应流）；tangent仅当两端均有且N/UV都保留时拼接，否则NULL。空网格是拼接单位元，非空侧的所有存在流保留；顺序和索引偏移沿用旧规则，src不改。计数不溢出的正常输入必支持，不要求给旧void操作增加失败返回或自合并支持。
- unweld同时按调用前的三角索引展开P/N/UV/tangent；create_indices=true重建连续索引，false保持旧索引数组不动（沿用原约定，此后是逐角非索引流，不再把旧索引用于这些数组）。缺失流继续NULL。
- translate保持N/T/w；rotate用原旋转矩阵同时传递N与T；非奇异scale对N用normalize(S^-T*N)，对T用S*T后在新N垂面正交单位化，w乘sign(x*y*z)。包括均匀负缩放。三角绕序和UV不改，保持原scale只移动几何的约定。输入切线流合法且法线有效。任一缩放因子为0时沿用旧法线塌缩行为，并释放切线置NULL。
- compute_normals及内部__compute_welded_normals写法线前释放切线；parametric必须等最终法线结束才生成切线，防止内部clone/weld递归创建切线。invert仅翻索引，不改变逐点N/UV/T/w；remove_degenerate若没有删面保留切线，确有删面则失效置NULL。
- weld保持原几何焊接、epsilon含义与weldmap语义，不改成渲染属性焊接；返回网格的N/UV/tangent均释放置NULL，防止旧空间排序/压缩后属性串号。内部welded normals仍可在焊后重建法线并按原map散回。源网格不变。无需为此修正旧焊接距离算法。

原有导出仍输出位置/UV/法线，不添加非标准OBJ切线字段。原形状测试及无切线调用继续可用。两种PAR_SHAPES_T配置都检查拆点容量，失败不交出半张网格。新增函数的分配失败需逐次注入覆盖，旧void操作只需正常分配下正确维护属性，不扩展其历史失败契约。
