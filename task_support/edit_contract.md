# 增量切线会话契约

公开接口按 edit_api.txt，头源由实现方新增。原 genTangSpace/genTangSpaceDefault 保持源码及ABI兼容；新旧路径可共享重构后的内部生产阶段。修改上游文件按其许可证标明改动。

## 输入与所有权

face_count>0，且安全表示原库4角编码及所有分配乘积。每面 count 为3或4；仅使用前 count 个角。position、normal、uv 有限，normal 长度与1偏差<=1e-5。angular_threshold 有限且在[0,180]。位置或UV退化合法，不将几何面积、UV面积非零作为前置条件；不支持其他多边形。创建拥有全部输入副本和 allocator 的值副本。调用方可释放/修改输入，结果不变。allocator 非NULL时两个函数都必须非NULL；所有 edit 路径分配（含复用核心阶段）经它完成，释放也经原 allocator，不用进程全局可变分配器切换。

update 替换原编号的完整面记录，每条更新的编号、角数及数值均先验证，角数不能改变；随后重复编号取最后一条。无效条目即使被后条覆盖也拒绝。前 count 个角按数值逐值比较，+0/-0相等；不按结构体padding比较。空批次或最终面记录没有变化，成功且 last_update 两列表清空，不做求值。输入更新数组不改写。失败返回0，面快照、全部角结果、last_update 数值及其有效性保持之前状态；随后合法更新仍可进行。分配失败也遵守此事务边界。成功返回1。

get 成功复制一个原面角的完整切线记录，失败返回0且输出不变。orientation 对应原 m_setTSpace 的布尔值，不用它代替真实 bitangent；长度保留 fMagS/fMagT。free(NULL) 安全，独立会话的状态及分配器互不干扰。get及stats在下一次成功update/free之前有效；创建后的stats可以列全部创建求值的原面。

## 与完整路径等价

每次成功后，以固定原面顺序从当前拥有记录喂给未近似的旧 genTangSpace、同一角阈值取参照。orientation逐值相同；tangent和bitangent分量误差<=5e-6；mag_s/mag_t误差<=5e-6*max(1,abs(reference))。退化面无自行约定的替代值；完整入口怎样继承，edit路径就怎样输出。改变某一角的属性后，要处理旧键移除和新键加入；共点但不同UV/法线不能盲合并。退化供体依赖和4角面两子三角属于同一原面，不能丢原面身份。

注意此提交 GenerateInitialVerticesIndexList 实际先比较UV对角线长度，平局才比较位置对角线。不要只按头注释重新实现另一种四边形规则。原面排序、精确P/N/UV焊接、角阈值分组、GROUP_WITH_ANY及DegenEpilogue供体规则都要在最终角输出上与当前生产实现一致。允许为正确性扩张局部闭包，但不能将一般连接分量整体刷新作为方案。

## 真实工作足迹

持久化旧、新属性反查与核心依赖；update 不扫描全体面/角构造新哈希表、不克隆整个网格或完整结果数组，也不全网重建分组。允许访问全局索引的键/树路径，但不线性枚举未相关记录。实际进入三角属性 InitTriInfo 或切线 GenerateTSpaces 求值的原面号集合是 evaluated_faces；只读一个缓存记录不算，重算后丢弃也算。published_faces 是本次替换角输出的原面号；未列出的输出保持原字节内容。均排序去重，真正改变切线的面必须发布，不要求列出的每面都数值改变。四边形重算两子三角仍记一个原面。

目标构建通过 -DMIKK_EDIT_TRACE=mikk_edit_trace_face 和强制包含 trace.h 提供跟踪。把 MIKK_EDIT_TRACE(original_face) 放到edit路径实际三角属性/切线求值入口，每次进入都调用；不能只在统计发布循环里补调用。测试在update前task_trace_reset，取 task_trace_size/task_trace_at 的去重集合独立对照 evaluated_faces。完整参照调用要与这个区间隔离。未定义宏时库无此外部依赖。README指出实际调用位置，源码复核这些位置；不能靠虚构列表通过局部约束。

连续64x64四边形平面：角位置(x,y,0)、法线(0,0,1)、UV(x/64,y/64)，每面四角按逆时针。替换中心面(32,32)的第0角 UV.u += 1/1024，evaluated_count<=96，仍对全网全部角独立核对。另建1024片彼此不同P/N/UV的隔离三角形，每片平移到(4*i,0,0)，改第512片一个UV，evaluated_count<=8。两例都用180度，非几何退化。不是通过缓存一套全量结果来伪装局部路径。大网格后续少量编辑工作空间和工作量随局部闭包增长；全量只在创建时允许。

## 回归与示例

test/edit.c 按四组注册真实内容测试，完整字段由旧回调独立收集；正常、镜像、不同阈值、跨来源属性焊接拆合、修改退化供体、四边形拆分变化和多次提交都对照。故障分配器从多个实际分配点失败，核快照/统计保留及释放无遗漏；无效记录和重复更新同测。示例 examples/edit.c 接收唯一文本文件路径，创建镜像接缝、更新一次，写原面角号和完整切线字段，打印实际求值/提交列表。文档说明结果指针寿命和浮点比较。
