# splice cut-plan 模式（联合选窗）

基础脚本验证原版 SoX 的双声道 splice、PCM 帧数、缓冲尺寸一致性和原有样本算术
测试。`sh task_support/build.sh` 与 `sh task_support/baseline.sh` 保持原有用途；
`sh task_support/check.sh` 在它们之后编译并运行 planner / pcm / lifecycle 三组
cut-plan 回归。

## 删除表（cut plan）

`cuts.txt` 每行两个十进制无符号整数 `a b`，表示**原输入帧坐标**里的半开删除
区间 `[a,b)`；一帧包含全部声道（多声道样本交错存放，剪接以帧为单位，不拆声道）。

- 空行、以及整行以 `#` 开头的注释允许出现；
- 除此之外的多余字段一律拒绝（不会被静默忽略）；
- 非空计划最多 64 段；每段必须 `a < b`；各段起点严格递增，区间互不重叠；
- 坐标始终对应原始输入，不会因为前面已删掉声音而调整后续 `a/b`；
- 数字按无符号十进制精确解析，超过 64 位范围即报错，不截断、不回绕。

## 命令

新模式只使用三角（线性）交叉淡化，不与旧的 `splice [-h|-t|-q] position…`
参数混用；旧位置参数和三种淡化模式行为完全不变。

```sh
sox -D --buffer 64 \
  -t raw -e signed-integer -b 32 -r 48000 -c 2 in.s32 \
  -t raw -e signed-integer -b 32 out.s32 \
  splice --cut-plan cuts.txt --overlap W --search S
```

- `--overlap W`：淡化窗长度（帧），范围 1..1024；
- `--search S`：每段可选的整数偏移半径（帧），范围 0..64；
- 声道数 1..8；输入必须有已知、有限、能被声道数整除的 `signal.length`。

## 偏移与约束

每段选一个整数偏移 `d_i ∈ [-S,S]`，该段两个端点一起平移：

- 左窗：输入 `[a_i+d_i-W, a_i+d_i)`
- 右窗：输入 `[b_i+d_i,    b_i+d_i+W)`

两个窗都必须完整落在实际输入 `[0,N)` 内；相邻接缝还要求

```
b_i + d_i + W <= a_(i+1) + d_(i+1) - W
```

等号合法：中间只剩两个不重叠的淡化窗，没有额外的原样帧。不存在满足全部
约束的偏移序列时，在消耗任何输入之前就明确报错（不会丢接缝、缩短 W 或自动
合并删除区间）。

## 精确代价与平局规则

候选代价是左右窗中**同位置、同声道**的 `sox_sample_t` 差值的平方和，所有声道
共同决定同一个偏移。差值用 64 位有符号整数精确求得，平方与累计用编译器提供
的 128 位无符号整数完成，不在 32/64 位上溢出，也不先混声道再求差、不使用浮点
近似（因此两个很大的整数代价不会被误判成相等）。

- 目标：各接缝代价总和最小的**合法**偏移序列；
- 平局：选整个有符号偏移向量按字典序最小者（先比 `d_0`，再比 `d_1`，…）；
- 求解是一次性的联合动态规划加回溯，空间 O(段数·(2S+1))，复杂度不随候选
  组合数指数增长；既不是逐段贪心，也不是发现相撞后再局部挪开。

## 渲染

先原样输出到第一个左窗之前；把对应左右窗按三角淡化交叉淡化成 W 帧；窗内
零基位置 `j` 的输出为

```
(1 - j/W) * left + (j/W) * right
```

取整与饱和沿用 SoX 的 `SOX_ROUND_CLIP_COUNT` 约定，`W=1` 也按同一公式
（此时 `j=0`，输出左样本）。两个接缝之间未参与淡化的保留帧逐样本原样复制。
不做重采样、音高变换或插零。输出长度恰为

```
N - sum(b_i - a_i) - 段数 * W
```

偏移只改变接缝位置，不改变输出长度。

## 离线存储范围

该效果是离线效果：`flow()` 阶段把 PCM 顺序写入由 `lsx_tmpfile()` 创建、
关闭即自动删除的临时文件，本身不输出；`drain()` 阶段才随机读候选窗并渲染。

内存中的 PCM 缓冲固定为：两个 W 帧窗（连续分配，共 `2*W*channels` 个样本）
加一个 8192 帧的 I/O 缓冲，合计

```
channels * (2W + 8192) <= channels * (4W + 2S + 8192)
```

个样本，不随整段录音长度增长；计划表、代价表和回溯元数据不计入 PCM 限额。
实际收到的采样数必须与声明长度相符；短读、临时文件读写失败和取消都有明确
诊断，并释放临时资源；磁盘 I/O 失败不会被当成剪辑正常完成。无论 flow 块大小
或 drain 输出容量如何变化，完整输出 PCM 逐样本一致；drain 结束后再次 drain
不再输出任何样本。
