This is a bounded, inert offline Dr. Memory log-processing task. SOURCE.json identifies every unchanged upstream file and the original gitlinks. Only postprocess.pl runs; context C files are retained for inspecting native error/module semantics, not claimed as a complete instrumentation build. Perl core modules, bash, and a C++17 compiler are required. No Python, package installs or network are needed at runtime.

Run `bash task_support/run.sh baseline` for the existing native parser and summary. Run `bash task_support/run.sh target` after implementing the specified feature and tests. Target deliberately fails on the initial missing feature. task_support contains contracts, entry binding and test registration support, not the implementation or completed goal tests. Keep these entry checks intact; source APIs may be implemented freely within the contract.
