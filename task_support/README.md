Run bash task_support/run.sh baseline for the unmodified scene, shared-skeleton, native attribute binding and draw controls. The GLSL loader reads original shader text; no npm install or GPU is needed.
Run bash task_support/run.sh target after implementation. It imports the required collector, requires a nonempty headless example and regression file, removes the previous scene-batches.json, executes the example, and runs membership/submission/integration cases with counted content checks. Regression cases must read the current example output. The ordinary controls run in both modes.
The recording-device controls exercise real production methods without claiming a hardware-rendered image. The support driver is not a semantic implementation or a completed scene-batching solution.
