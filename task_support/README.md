# Offline source-analysis entry
Use a JDK 17+ and Go 1.22+ (local toolchain). Run `bash task_support/run.sh baseline` from the repository root. The production library is compiled directly with `javac --release 8`; Gradle, Maven, JUnit, annotation processing and online package repositories are not required. The original upstream source/tests remain unchanged; the existing standard-library-only PlainTextPrinter is compiled as an adapter, and LegacySwitch provides a local ordinary-switch smoke case. This does not run the upstream JUnit suite.

Only the analyzer is launched on the JVM. The class path contains `.task-build/classes` and `.task-build/analyzer`, never `.task-build/fixtures` or recompiled output. `task_support.Analyze <directory> <internal-name>` reads the analyzed class through the production Loader API and outputs production decompiler text. Do not use Class.forName, reflection invocation or a custom defining ClassLoader on a fixture. Fixtures may be compiled, inspected with javap, and recompiled from decompiler text; their methods must not execute.

Add content assertions in `task_support/switch_regression_test.go`, package `task_support`; use `taskcheck.Run` and `c.Check` from `harness.local/jdcore/task_support/taskcheck`. The Go test working directory is `task_support`, so use the repository's parent directory when invoking Java tools. New static AST probes under `task_support/java` are automatically compiled against current production classes; they can use DeserializeClassFileProcessor and ClassFileToJavaSyntaxProcessor with Message, then inspect the production CompilationUnit through visitors. Do not replace the production pipeline with source-text construction.

`bash task_support/run.sh target` compiles every production `.java` including newly added files, runs TestSwitchStackMerges, TestSwitchTypes and TestSwitchCompatibility, requires completed nonzero assertion counts, and finally repeats baseline observations. GOMODCACHE and GOCACHE are task-local directories under `.task-build`; GOPROXY/GOSUMDB are off and GOTOOLCHAIN is local. The baseline prints the current modern output and actual compiler statuses; a zero javac status alone does not establish preservation of switch-arm values.
